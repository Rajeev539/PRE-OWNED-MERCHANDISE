# 🛍️ Pre-Owned Merchandise

### A Web-Based Platform for Buying and Selling Second-Hand Products

## 📌 Project Overview

Pre-Owned Merchandise is a web-based marketplace designed to simplify the buying and selling of second-hand products. The platform provides a centralized environment where users can register, explore available products, list their unused items for sale, and connect with potential buyers.

The application aims to make pre-owned products more accessible and affordable while encouraging the reuse of resources and reducing unnecessary waste.

## 🎯 Project Objectives

* Develop a centralized platform for buying and selling pre-owned products.
* Provide secure user registration and login functionality.
* Enable sellers to upload product details and images.
* Allow buyers to search products using categories, price ranges, and locations.
* Implement an admin module to monitor users, products, and feedback.
* Improve transparency through ratings and feedback.

## ✨ Key Features

* **User Authentication:** Registration and login functionality.
* **Product Management:** Add and manage products with descriptions, prices, and images.
* **Product Search:** Search and filter products based on categories, prices, and locations.
* **Buyer Module:** Browse products and view seller information.
* **Seller Module:** List multiple products for potential buyers.
* **Admin Dashboard:** Manage registered users, product listings, and feedback.
* **Feedback & Ratings:** Allow users to share their experiences and reviews.
* **Database Management:** Maintain structured records of users, products, and transactions.

## 🏗️ System Modules

The application consists of five major modules:

1. **Admin Module:** Monitors registered users, product listings, and customer feedback.
2. **User Module:** Handles user registration and login.
3. **Seller Module:** Allows users to upload and manage products.
4. **Buyer Module:** Enables users to browse products, apply search filters, and contact sellers.
5. **Feedback Module:** Collects ratings and comments to improve transparency.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### Prerequisites

* Python installed on your system.
* MySQL Database Server.
* Required Python packages.
* A web browser.

### Steps to Run

**1. Clone the Repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the Project Directory**

```bash
cd Pre-owned-Merchandise
```

**3. Install Required Dependencies**

```bash
pip install -r requirements.txt
```

**4. Configure the Database**

* Install and configure MySQL.
* Open the MySQL console.
* Execute the SQL commands provided in `DB.txt` to create the required database and tables.

**5. Start the Application**

Run the `run.bat` file to start the Python server.

**6. Open the Application**

Open your browser and navigate to:

```text
http://127.0.0.1:8000/index.html
```

The application will be accessible locally.
